## Português (Brasil) — pt-BR

**Nome do app** (até 30)

```
Network Backup Tool
```

**Descrição curta** (até 80)

```
Copie fotos e arquivos entre celular e PC pela rede local, rápido e sem nuvem.
```

**Descrição completa** (até 4000)

```
Network Backup Tool copia fotos, vídeos e arquivos entre o seu celular e outros aparelhos da mesma rede Wi-Fi — computadores com Windows, Linux ou macOS, ou outro celular Android. Tudo vai direto de um aparelho para o outro: sem nuvem, sem cabo, sem cadastro e sem limite de tamanho.

Feito para quem precisa fazer backup ou trocar de aparelho: técnicos de informática, quem está migrando para um celular novo ou quem só quer passar as fotos para o computador.

COMO FUNCIONA
• No aparelho que vai receber, toque em Receber → Iniciar recepção. Aparece um código de 6 dígitos.
• No aparelho que vai enviar, escolha o que copiar, toque no aparelho que aparece sozinho na lista, digite o código e envie.

DESTAQUES
• Rápido: usa várias conexões ao mesmo tempo para aproveitar toda a velocidade da rede.
• Retomada: se a cópia for interrompida, envie de novo — o que já chegou igual é pulado.
• Seguro: só conecta quem sabe o código, e cada bloco de dados é conferido na chegada.
• Pastas do aparelho com um toque: câmera (DCIM), imagens, documentos, downloads, vídeos, músicas e mídias do WhatsApp.
• Escolha se as pastas chegam só pelo nome ou com o caminho completo.
• Acompanhe tudo: arquivo atual, barra de progresso, velocidade e tempo restante.
• Encontra os aparelhos da rede automaticamente, sem digitar endereço.
• Funciona entre Android, Windows, Linux e macOS, em qualquer combinação.
• Português, inglês e espanhol, tema claro e escuro.

PRIVACIDADE
Os arquivos vão só para o aparelho que você escolher, dentro da sua rede. O app não tem servidores, não coleta dados e não exibe anúncios. Código aberto (licença MIT): github.com/leddzeppellin/network-backup-tool

PERMISSÕES
• Acesso a todos os arquivos: necessário para ler as pastas que você escolhe enviar (como DCIM e as mídias do WhatsApp) e para gravar os arquivos recebidos em Download/NetBackupTool.
• Wi-Fi e rede: para encontrar os aparelhos e transferir os arquivos na rede local.

Para usar no computador, baixe o programa gratuito em github.com/leddzeppellin/network-backup-tool/releases
```

## English (United States) — en-US

**App name**

```
Network Backup Tool
```

**Short description**

```
Copy photos and files between phone and PC over your local network. No cloud.
```

**Full description**

```
Network Backup Tool copies photos, videos and files between your phone and other devices on the same Wi-Fi network — Windows, Linux or macOS computers, or another Android phone. Everything goes straight from one device to the other: no cloud, no cable, no sign-up and no size limit.

Made for anyone who needs to back up or switch devices: IT technicians, people moving to a new phone, or anyone who just wants their photos on the computer.

HOW IT WORKS
• On the receiving device, tap Receive → Start receiving. A 6-digit code appears.
• On the sending device, pick what to copy, tap the device that shows up in the list by itself, type the code and send.

HIGHLIGHTS
• Fast: uses several connections at once to make full use of your network speed.
• Resume: if a copy is interrupted, just send again — files already there are skipped.
• Secure: only someone with the code can connect, and every block of data is verified on arrival.
• Device folders in one tap: camera (DCIM), pictures, documents, downloads, videos, music and WhatsApp media.
• Choose whether folders arrive by name only or with their full path.
• Follow everything: current file, progress bar, speed and time left.
• Finds devices on the network automatically, no address typing needed.
• Works between Android, Windows, Linux and macOS, in any combination.
• Portuguese, English and Spanish, light and dark theme.

PRIVACY
Files only go to the device you choose, inside your own network. The app has no servers, collects no data and shows no ads. Open source (MIT license): github.com/leddzeppellin/network-backup-tool

PERMISSIONS
• All files access: needed to read the folders you choose to send (such as DCIM and WhatsApp media) and to save received files to Download/NetBackupTool.
• Wi-Fi and network: to find devices and transfer files on the local network.

To use it on a computer, download the free program at github.com/leddzeppellin/network-backup-tool/releases
```
